# SQL - Structured Query Language

*** SQL is used to CREATE, RETRIEVE, UPDATE, DELETE data from DATABASE. ***

- Relational (Keys) = SQL
- Non Relational    = NoSQL


- To write SQL statements we need to help of a special piece of software called DBMS.
- Database Management System
![DBMS](image.png)

*** Different DBMS systems we can use:
- MySQL
- Microsoft SQL Server
- Oracle
- PostgreSQL
- etc
Each of these database management systems all use ***SQL***; but there's subtle nuances between these syntax of each DBMS.

- Here, we will learn **MySQL**!!
- And also use **Microsoft Workbench**!!
- MySQL Workbench is a Database Management Tool (GUI-based client for MySQL).
